# Sound effect credits

All recordings in this folder are **CC0** (public domain) and come from
OpenGameArt.

## "Battle at sea" by Thimras

https://opengameart.org/content/battle-at-sea

| File | Original file | Used for |
| --- | --- | --- |
| `gun.ogg` | `cannon_fire.ogg` | A ship firing |
| `hit.ogg` | `cannon_hit_ship_short.ogg` | A shell striking a ship |
| `miss.ogg` | `cannon_miss.ogg` | A shell landing in the water |
| `sink.ogg` | `ship_destroyed_short.ogg` | A ship being destroyed |

## "Their Coming (generic horn sound)" by StumpyStrust

https://opengameart.org/content/their-coming-generic-horn-sound

| File | Original file | Used for |
| --- | --- | --- |
| `enemy_horn.ogg` | `theircoming3.ogg` | The far fleet's answering horn in the opening |

All files were converted to mono, trimmed and level-matched. The viewer plays
the enemy horn pitched down, filtered and quiet, so it sounds distant. Run
`python scripts/pack_sounds.py` after changing any of them.
